# 用户手册 (User Manual)

欢迎阅读 `云章·经籍` 用户手册。本手册将引导您使用平台的核心功能。

---

## 1. 📖 阅读前台 (User Web)

### 1.1 浏览与检索
- **藏书阁**: 在首页可查看最新推荐的书籍列表。
- **分类筛选**: 通过标签（如“经部”、“史部”）快速定位感兴趣的类别。
- **全文检索**: 支持输入书名、作者或正文关键词进行检索。

### 1.2 阅读体验
- **沉浸式阅读**: 点击书籍封面进入阅读页，系统会自动开启宋朝古风阅读模式。
- **AI 辅助**:
    - **划词翻译**: 在古文段落中双击或长按，即可呼出 AI 翻译助手。
    - **实体百科**: 点击文中高亮的人名、地名，可查看知识图谱详情。

### 1.3 个人中心
- **书架管理**: 收藏您喜爱的书籍，支持离线下载（需客户端支持）。
- **阅读历史**: 继续上次的阅读进度。

---

## 2. 🛠️ 管理后台 (Admin Portal)

### 2.1 登录与权限
- **地址**: 访问 `/admin` (默认开发环境: `http://localhost:5173`)
- **账号**: 使用管理员分配的账号 (如 `admin`) 登录。
- **角色**:
    - **掌书官 (超级管理员)**: 拥有所有权限。
    - **编修 (内容编辑)**: 仅负责书目录入与校对。

### 2.2 书目编目
1. 进入 **"典籍修撰" > "书目编目"**。
2. 点击 **"新增书目"**，填写书名、作者、朝代、版本等元数据。
3. 上传 TEI XML 或 Markdown 格式的正文文件。
4. 系统将自动解析章节结构并存入数据库。

### 2.3 知识图谱入库 (RAG)
1. 进入 **"文渊阁" > "入库校验"**。
2. 选择要处理的书籍，点击 **"开启向量化"**。
3. 系统将调用后台 AI 模型 (Ollama/OpenAI) 对文本进行切片、嵌入并存入 Milvus 向量库。
4. **验证**: 如果任务失败，可查看日志并在原位置重试。

### 2.4 用户与鉴权
- **会话管理**: 在 **"清谈雅集"** 中查看活跃的 WebSocket 连接。
- **JWT 令牌**: 系统使用 RSA-256 签名的 JWT 进行鉴权，公钥通过 API 网关暴露。

## 3. 常见问题排查

### Q1: 无法登录后台？
- 请确认后端 `user-service` 是否正常运行，且数据库连接配置正确。
- 检查浏览器控制台是否有网络请求错误 (401/403)。

### Q2: AI 翻译响应慢？
- 如果使用本地 Ollama 模型，受限于硬件资源，响应可能会有延迟。建议在 GPU 服务器上部署。
- 检查 `knowledge-service` 日志中是否有模型超时报警。

### Q3: 搜索结果不准确？
- 请尝试更新 Milvus 索引，或者在后台手动触发一次全量重建索引任务。
- 只有经过向量化处理的书籍才能被语义搜索检索到。
